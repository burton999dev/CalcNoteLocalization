# Localization Project for CalcNote

This project manages the localization resources for CalcNote, a calculator app that combines notepad functionality with calculation capabilities.  

## Contributing Translations

While I'm a native Japanese speaker with some English proficiency, I welcome contributions from speakers of other languages to improve CalcNote's translations. If you notice any incorrect translations or have suggestions for improvements, please:  

1. Create an Issue describing the translation concern
2. Submit a Pull Request with your proposed changes
3. Include context or explanations for the suggested translations when possible

Your contributions help make CalcNote more accessible to users worldwide.

## Right-to-Left (RTL) Language Support

Currently, CalcNote does not support Right-to-Left languages like Arabic. This limitation exists because I'm uncertain about the optimal way to handle the mixed display of mathematical expressions and text in RTL languages.  
If you are fluent in both English and Arabic (or other RTL languages) and would like to help with localization, please contact me at burton9999dev@gmail.com. Your expertise would be invaluable in implementing proper RTL support.  

## Resources

All string resources are stored in XML format within this repository. Feel free to examine the existing translations and suggest improvements through Issues or Pull Requests.
